#  Synthetic E-Commerce Data Analysis Project

##  Overview
An end-to-end data analysis workflow utilizing Python to clean raw synthetic transaction registries, evaluate customer age distributions, and break down preferred localized payment strategies.

##  Tech Stack
* **Language:** Python
* **Libraries:** Pandas (Data manipulation), Matplotlib (Data Visualization)

## 💡 Key Business Findings
1. **Target Demographic:** The primary customer base is concentrated heavily around middle-aged consumers, with an overall average age sitting at **41 years old**.
2. **Payment Channel Optimization:** **Cash on Delivery (CoD)** reigns as the most prominent payment protocol with 370 instances. Digital solutions lag slightly behind with Bank Transfers at 322 and Credit Cards at 308. 
3. **Data Quality Issues:** Identified and mapped structural gaps within the source data, pinpointing exactly 201 missing fields under the review scoring metrics and 103 blank items under user gender fields.

## 📂 Deliverables Generated
* `analysis.py` - Core execution script
* `age_distribution.png` - Visual distribution chart tracking customer demographics
